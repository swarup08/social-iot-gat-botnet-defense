# GAT for Social IoT Botnet Containment

Graph Attention Networks (GAT) + Reinforcement Learning (RL) for securing
Social IoT networks against botnet propagation, with an explainability (XAI)
layer and a full statistical evaluation harness. Built over 4 milestones
following the project roadmap (`docs/Swarup_Research.pdf`), incorporating
supervisor feedback from a prior attempt (see `CLAUDE.md`).

**Status: all 4 milestones complete.** Report and slide deck are the only
remaining deliverables (pending supervisor sign-off on framing).

## Headline finding (honest summary, see `NOTES.md` for full detail)

Edge pruning generally slows botnet spread while preserving core-task
performance. However, across 40 independent graph instances with paired
statistical testing (Holm-corrected), **GAT+RL does not beat simple
structural heuristics (degree-centrality, highest-p_uv) on containment** --
it ties or loses, at far higher compute cost. RL reliably beats random
pruning and ties a greedy oracle. This core containment finding is also
shown to be conditional on GAT architecture (heads=4, depth=2 specifically)
-- a robustness caveat documented via dedicated ablations, not glossed over.

## Setup

```bash
pip install -r requirements.txt
```

## Milestone 1 -- Social IoT graph + botnet propagation simulator

Scale-free (Barabasi-Albert) graph, structural node/edge features,
feature-driven infection probability p_uv = sigmoid(beta^T phi(...)),
synchronous round-based propagation simulator.

```bash
python demo_milestone1.py
```

## Milestone 2 -- GAT edge importance + static pruning

GAT node classifier (benign/compromised), degree-corrected attention
extraction, threshold and top-k static pruning, security/utility trade-off.

```bash
python demo_milestone2.py
python demo_milestone2_attention.py
python demo_milestone2_convergence.py
python demo_milestone2_pruning.py
```

## Milestone 3 -- RL adaptive pruning + XAI hooks

Custom DQN agent learning an edge-pruning policy on top of GAT scores,
with per-decision trajectory logging for explainability.

```bash
python demo_milestone3_env.py
python demo_milestone3_dqn.py
python demo_milestone3_vs_baselines.py
python demo_milestone3_reward_diagnostic.py
python demo_milestone3_xai.py
```

## Milestone 4 -- Baselines, ablations, stress tests, statistical harness

Full baseline suite (random, degree-centrality, betweenness-centrality,
highest-p_uv, greedy oracle) alongside GAT+RL; ablations (GAT heads/depth,
RL reward weights, noisy/incomplete features); stress tests (graph
size/density, attack aggressiveness); 40-graph statistical harness with
paired significance tests, Holm correction, effect sizes, and compute cost.

```bash
python demo_milestone4_harness.py              # ~60 min, the core 40-graph evaluation
python demo_milestone4_reward_ablation.py
python demo_milestone4_stress_tests.py
python demo_milestone4_gat_ablations.py
python demo_milestone4_depth_and_masking_ablation.py
python demo_milestone4_infection_curves.py
```

Harness results are persisted in `harness_summary.csv` (per-method mean/std
containment ratio, utility, compute cost) and `harness_paired_tests.csv`
(paired t-tests with Holm-corrected p-values). XAI outputs are persisted in
`pruned_edge_characteristics.csv` and `hub_node_pruning_summary.csv`.
